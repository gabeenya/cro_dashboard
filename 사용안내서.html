1시작하기 — 회원가입과 로그인

1-1. 회원가입 (처음 한 번만)

  1. 접속하면 로그인 화면이 나옵니다.
  2. 위쪽의 [회원가입] 탭을 누릅니다.
  3. 아래 항목을 입력합니다. (별표 *는 필수)
    • 성명 * / 사번 *
    • 소속 계열사 * — 패션 / 유통 / 외식 / 파크 / 건설 / 소법인 / 기타 중 선택
    • 부서 *
    • 이메일 * — 로그인할 때 쓰는 아이디입니다
    • 비밀번호 * — 6자 이상, 한 번 더 입력해 확인
  4. [가입 신청] 버튼을 누릅니다.
  5. “관리자 승인 대기 중” 화면이 나오면 신청 완료입니다.
⚠️ 가입 직후에는 바로 로그인할 수 없습니다. 관리자가 승인해야 이용할 수 있습니다.

1-2. 승인 기다리기

  • 관리자가 승인하면 별도 알림 없이 로그인이 가능해집니다.
  • 승인 전에 로그인하면 다시 “승인 대기 중” 화면이 나옵니다. 조금 기다렸다 다시 시도해 주세요.
  • 급할 경우 관리자(가비님)에게 직접 승인을 요청하세요.

1-3. 로그인

  1. [로그인] 탭에서 이메일과 비밀번호를 입력합니다.
  2. [로그인] 버튼을 누르면 메인 화면(대시보드)으로 들어갑니다.
  3. 로그아웃은 화면 우측 상단(또는 메뉴)의 로그아웃을 누르면 됩니다.

  • 사이드바의 계열사 이름 옆 숫자는 그 계열사에 등록된 리스크 건수입니다.
  • 계열사 이름을 누르면 그 계열사만 따로 볼 수 있고, 전사 8대 리스크 관리 현황을 누르면 전체로 돌아옵니다.

3대시보드 보는 법 (전사 8대 리스크 관리 현황)

첫 화면에서 전체 또는 선택한 계열사의 현황을 봅니다.

  • 상단 KPI 카드 — 등급별(위험 주의 안전) 건수와 비율
  • 월별 모니터링 추이 — 월별 ‘전체’와 ‘위반’(=위반+완료) 건수 추이 그래프. 그래프 위 드롭다운으로 보이는 기간(직전 N개월 + 현재 + 이후 M개월, 기본 직전 3 + 현재 + 이후 8 = 12개월)을 조정할 수 있습니다.
  • 리스크 영역별 현황 — 8대 리스크 영역별 분포
  • 계열사별 / 브랜드별 현황 — 어디에 리스크가 몰려 있는지
  • 위험도별 분류 / 위험 등급 리스크 — 주의해서 봐야 할 항목

상단 필터에서 등급(전체/위험/주의/안전) 등을 골라 원하는 것만 볼 수 있습니다.

알림 카드 (장기 미해결 / 이상 급증 영역)

대시보드 상단에 주의가 필요한 상황을 자동으로 짚어주는 알림 카드 2개가 있습니다. 카드를 누르면 해당 항목 목록이 뜹니다.

  • ⏰ 장기 미해결 — 등록 후 기준 일수가 지났는데 아직 ‘위반’ 상태(=조치가 끝나지 않음)인 항목 수입니다. ‘모니터링’(문제없음)과 ‘완료’(조치끝)는 제외됩니다. 카드 안 드롭다운에서 기준 일수(10 / 15 / 30 / 60 / 90일, 기본 10일)를 바꿀 수 있습니다.
  • 📈 이상 급증 영역 — (계열사 × 영역 대분류) 묶음별로, 최근 1개월 위반 건수가 전월 1개월 대비 20% 이상 증가했고 동시에 최근 1개월 위반이 3건 이상인 영역의 수입니다. (작은 숫자 변동으로 인한 오탐을 막기 위해 3건 미만은 제외)
💡 등급(위험/주의/안전)은 직접 입력하지 않습니다. 시스템이 자동으로 계산합니다. (기준은 아래 6번 참고)

4데이터 입력하기 (모니터링값 등록)

사이드바 [데이터 입력] 화면에서 등록합니다. 방법은 두 가지 — 한 건씩 입력(4-1)과 엑셀 일괄 업로드(4-2)입니다.

먼저 알아두기 — ‘상태’ 3종과 ‘건수’

입력에서 가장 중요한 개념입니다. 상태에 따라 건수가 어디로 집계되는지가 달라집니다.

상태의미건수 집계
모니터링점검했고 위반이 없는 정상 상태 (조치할 것 없음)모니터링 건수로 집계
위반위반이 발견되어 조치 중인 상태위반 건수로 집계
완료위반이 있었고 조치가 끝난 상태위반 건수로 집계
💡 집계 규칙: ‘위반’ 건수 = 위반 + 완료(위반이 발생한 모든 건), ‘전체’ = 모니터링 + 위반 + 완료. 등급(위험/주의/안전)은 입력하지 않습니다 — 시스템이 자동 계산합니다(6번 참고).

4-1. 한 건씩 입력

“데이터 입력” 카드에서 작성합니다. (별표 *는 필수)

  1. 계열사 * 를 먼저 고릅니다. → 그 계열사의 브랜드/조직 목록이 자동으로 나타납니다.
  2. 브랜드/조직 * 선택 (유통 계열사는 매장 칸이 추가로 나타나며, 선택사항입니다.)
  3. 등록일 * — 기본값은 오늘 날짜
  4. 영역 대분류 * 를 고르면 → 관련 영역 중분류가 자동으로 나타납니다. (중분류는 선택)
  5. 상태 * 를 버튼으로 선택합니다. (모니터링 / 위반 / 완료 — 뜻은 위 표 참고)
  6. 건수 * — 고른 상태에 맞춰 라벨이 바뀝니다(예: “위반 건수”). 숫자를 반드시 입력하세요.
  7. 리스크명 * — 제목을 입력
  8. 조치사항 — 드롭다운에서 고릅니다. (선택)
    • 징계 선택 시 → 이름 · 양형 입력란이 나타납니다.
    • 징계 외 선택 시 → 조치 내용(자유 입력)란이 나타납니다.
  9. 비고 — 추가 메모 (선택)
  10. [저장] 을 누르면 등록됩니다. 아래 “최근 입력 내역”에서 방금 넣은 내용을 확인·수정할 수 있습니다.
잘못 눌렀다면 [초기화] 로 폼을 비울 수 있습니다.

4-2. 엑셀로 한꺼번에 올리기 (일괄 업로드)

여러 건을 한 번에 등록할 때 사용합니다. 같은 화면의 “일괄 업로드 (엑셀)” 카드에서 네 단계로 진행됩니다.

🔒 ‘보안(암호화)이 해제된’ 엑셀 파일만 업로드할 수 있습니다. 회사 문서보안(DRM)이나 비밀번호가 걸린 파일은 업로드되지 않거나 “파일 처리 실패” 오류가 납니다. → 파일의 보안을 해제(복호화)한 뒤, 일반 .xlsx로 저장해서 올려주세요.
  1. 양식 다운로드 — [양식 다운로드]를 누르면 리스크_일괄업로드_양식_날짜.xlsx가 받아집니다. 이 양식에는 계열사·브랜드·영역 목록이 자동으로 들어가 있어 드롭다운으로 고를 수 있습니다.
  2. 엑셀 작성 — 파일에는 시트가 3개 있습니다. ‘입력’ 시트의 2행부터만 작성하세요. (‘안내’=작성요령, ‘_참조’=드롭다운용 숨김 시트(건드리지 마세요)) 각 항목은 아래 표 참고.
  3. 엑셀 업로드 → 검증 — 저장한 파일을 [엑셀 업로드]로 올리면 바로 저장되지 않고 먼저 검증 결과가 표시됩니다: 등록 가능 N건 / 오류 N건, 오류는 “○행: 사유” 형태로 안내됩니다.
  4. 실제 저장 — [유효한 N건 등록] 버튼을 눌러야 비로소 저장됩니다. 오류 행은 빼고 정상 행만 등록됩니다. (취소하려면 [취소])

‘입력’ 시트 항목 (별표 * = 필수)

열(헤더)설명
등록일(YYYY-MM-DD) *예 2026-06-01. 엑셀 날짜 셀도 인식됩니다.

오류 메시지해결 방법

브랜드 ‘○○’는 ‘○○’에 속하지 않음계열사를 먼저 맞춘 뒤 그 계열사의 브랜드를 선택

등록일 누락/형식 오류YYYY-MM-DD 형식으로

5등록한 내용 보기·고치기 (모니터링 리스트)

사이드바 [모니터링 리스트] 에서 등록된 리스크를 표로 봅니다.

  • 상단 필터로 계열사 / 영역 대분류 / 영역 중분류 / 등급 / 상태 별로 골라 볼 수 있습니다.
  • 표에는 등록일, 계열사, 브랜드/조직, 리스크명, 등급, 상태, 위반건수, 모니터링건수, 위반율이 나옵니다.
  • 각 줄에서 수정 또는 삭제를 할 수 있습니다.
    • 수정을 누르면 창이 떠서 내용을 고친 뒤 저장합니다.
    • 삭제는 되돌릴 수 없으니 신중히 사용하세요.

6등급은 어떻게 정해지나요? (자동 산정 기준)

등급은 사람이 정하지 않고 다음 기준으로 자동 계산됩니다.

등급해당 조건 (하나라도 맞으면)
🔴 위험‘위반’ 상태로 30일 이상 경과 / 같은 위반(브랜드+영역)이 최근 30일 내 10건 이상 반복 / 해당 영역의 이번 달 등록이 전월 대비 20% 이상 증가
🟠 주의‘위반’ 상태로 15일 이상 경과 / 같은 위반 5건 이상 / 전월 대비 10% 이상 증가(20% 미만)
🟢 안전위에 해당하지 않음
참고 ① “처리 지연(N일 이상)”은 상태가 ‘위반’인 항목만 셉니다. ‘모니터링’(문제없음)과 ‘완료’(조치끝)는 지연 계산에서 제외됩니다.
참고 ② 한편 추이 그래프·집계의 ‘위반’ 건수는 상태가 위반 + 완료인 항목을 함께 셉니다(위반이 발생한 모든 건). — 둘은 쓰임이 달라 기준이 다릅니다.

7AI 분석 사용하기

사이드바 [AI 분석] 에서 데이터를 바탕으로 AI 분석을 받을 수 있습니다.

  1. 계열사 1개를 고릅니다. (전체 또는 특정 계열사)
  2. 원하는 분석 항목을 골라 체크합니다. (여러 개 선택 가능)
    • 위험도 식별 / 트렌드 분석 / 권고 액션 플랜 / 추세·패턴 / 유사 사례 매칭 / 계열사별 비교
  3. 분석 실행 버튼을 누르면 잠시 후 분석 결과가 표시됩니다.
  4. 결과 위쪽에 사용된 분량(토큰) 정보가 함께 표시됩니다.
분석은 등록된 데이터를 요약해 처리하므로, 데이터가 많을수록 더 의미 있는 결과가 나옵니다.

8보고서 내려받기 (PPT)

사이드바 [보고서 다운로드] 를 누르면 작은 창이 뜹니다.

  1. 계열사를 고릅니다. (전체 또는 특정 계열사 한 곳)
  2. [다운로드] 를 누르면 PPT 파일이 만들어져 내려받아집니다.

보고서에는 표지, 그룹 KPI, 계열사×8대 리스크 매트릭스, 영역별 상세, 요약 카드 등이 자동으로 들어갑니다.

9관리자용 — 회원 관리 (관리자만 보임)

관리자 계정으로 로그인하면 사이드바에 [회원 관리] 메뉴가 나타납니다.

  • 가입 신청 (승인 대기) 목록
    • [승인] — 해당 사용자가 로그인할 수 있게 합니다.
    • [삭제] — 신청을 목록에서 제거합니다. 삭제된 사용자는 로그인할 수 없게 됩니다. (완전히 계정을 없애려면 Supabase 관리 화면에서 별도 처리가 필요합니다.)
  • 승인된 회원 목록
    • [승인 해제] — 다시 로그인하지 못하도록 권한을 거둡니다. (재승인하면 다시 가능)

10자주 묻는 질문 (FAQ)

Q. 가입했는데 로그인이 안 돼요.
→ 관리자 승인 전입니다. 승인되면 로그인할 수 있습니다. 오래 걸리면 관리자에게 문의하세요.

Q. 비밀번호를 잊었어요.
→ 관리자에게 문의하세요.

Q. 등급을 직접 바꾸고 싶어요.
→ 등급은 자동 계산이라 직접 입력하지 않습니다. 상태·건수·등록일 등을 정확히 입력하면 등급이 알맞게 반영됩니다.

Q. 엑셀 업로드에서 “헤더가 양식과 다릅니다”가 떠요.
→ 예전 양식을 쓰셨을 가능성이 큽니다. 양식을 새로 다운로드해 다시 작성하세요.

Q. 일괄 업로드에서 “파일 처리 실패”가 떠요.
→ 파일에 문서보안(DRM)이나 비밀번호(암호화)가 걸려 있으면 읽지 못합니다. 보안을 해제한 뒤 일반 .xlsx로 저장해 다시 올려주세요.

Q. 일괄 업로드를 했는데 일부만 등록됐어요.
→ 정상입니다. 검증에서 오류가 난 행은 제외하고 정상 행만 등록됩니다. 화면의 “○행: 사유” 안내를 보고 해당 행만 고쳐 다시 올리세요. (이미 들어간 행을 또 올리면 중복될 수 있으니, 오류였던 행만 남겨 올리는 것을 권장합니다.)

Q. 엑셀 ‘입력’ 시트에서 브랜드 드롭다운이 비어 있어요.
→ 계열사를 먼저 선택해야 그 계열사의 브랜드가 나옵니다. 영역 중분류도 마찬가지로 영역 대분류를 먼저 고르세요.

Q. 모바일에서도 되나요?
→ 네. 화면이 작으면 왼쪽 위 메뉴 버튼으로 사이드바를 열고 닫을 수 있습니다.
