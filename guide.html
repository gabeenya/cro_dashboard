1시작하기 — 회원가입과 로그인

1-1. 회원가입 (처음 한 번만)

  1. 접속하면 로그인 화면이 나옵니다.
  2. 위쪽의 [회원가입] 탭을 누릅니다.
  3. 아래 항목을 입력합니다. (별표 *는 필수)
    • 성명 * / 사번 *
    • 소속 계열사 *
    • 부서 *
    • 이메일 * — 로그인할 때 쓰는 아이디입니다
    • 비밀번호 * — 6자 이상, 한 번 더 입력해 확인
  4. [가입 신청] 버튼을 누릅니다.
  5. "관리자 승인 대기 중" 화면이 나오면 신청 완료입니다.
⚠️ 가입 직후에는 바로 로그인할 수 없습니다. 관리자가 승인해야 이용할 수 있습니다.

1-2. 승인 기다리기

  • 관리자가 승인하면 별도 알림 없이 로그인이 가능해집니다.
  • 승인 전에 로그인하면 다시 "승인 대기 중" 화면이 나옵니다.
  • 급할 경우 관리자(가비님)에게 직접 승인을 요청하세요.

1-3. 로그인

  1. [로그인] 탭에서 이메일과 비밀번호를 입력합니다.
  2. [로그인] 버튼을 누르면 메인 화면(대시보드)으로 들어갑니다.
  3. 로그아웃은 사이드바 하단의 로그아웃 버튼을 누르면 됩니다.

3대시보드 보는 법

첫 화면은 위에서부터 아래 순서로 다음 내용을 보여줍니다.

3-1. KPI 카드 4장

카드내용
연누적올해 1/1부터 지금까지의 위반·모니터링 건수, 위반율
월누적이번 달 1일부터 지금까지의 위반·모니터링 건수, 위반율
조치중아직 처리 안 된 건수, "14일 초과"(마우스를 올리면 상세 목록 팝업), 처리완료율
회수금액부실채권 중 '해결' 처리된 금액 합계와 회수율
이 4장의 집계에서는 감사·부실채권 영역은 제외됩니다(감사는 등급 산정 대상이 아니고, 부실채권은 금액 기준이라 건수 집계와 성격이 달라서). 회수금액 카드가 부실채권 몫을 따로 보여줍니다.

3-2. 리스크 노출/측정판

계열사(또는 브랜드) × 8대 영역(감사·재고 제외 6개)을 격자로 보여주는 표입니다.

  • 종합등급 열 — 그 법인/브랜드의 전체 등급(A~F, 100점 만점 점수 함께 표시)
  • 각 영역 칸에는 등급 배지와 위반/전체 건수가 함께 표시됩니다.
  • 표 오른쪽 위 드롭다운으로 전체(계열사별) ↔ 특정 계열사의 브랜드별 보기를 바꿀 수 있습니다.
  • 누적/지정월 드롭다운 + 기준월 선택 — 누적을 고르면 올해 1/1부터 지금까지, 특정 월을 고르면 그 달 데이터만(그 달 1일~말일) 기준으로 등급이 다시 계산됩니다.
  • 제목 옆 "?" 버튼을 누르면 등급 산정 기준 전체 설명이 뜹니다. 등급 기준 자세한 내용은 6번 참고.

3-3. 감사 영역 카드

측정판 아래에 감사 데이터 전용 카드 4장(조치완료/적발 건수, 경징계·중징계·형사고발 건수)이 있고, 같은 줄의 누적/지정월 드롭다운으로 기간을 바꿀 수 있습니다. 이 설정은 바로 아래 조치사항 표(징계현황, 영역별 특이사항)에도 함께 적용됩니다.

3-4. 그래프 3종 + 최근 모니터링 리스트

  • 월별 모니터링 추이 — 월별 '전체'와 '위반'(위반+완료) 건수 추이. 그래프 위 드롭다운으로 기간 조정 가능.
  • 리스크 영역별 현황 — 8대 영역별 분포 도넛 그래프
  • 계열사별 현황 — 계열사별 모니터링(전체)/위반 건수 막대 그래프. 막대를 누르면 해당 계열사뷰로 이동합니다.
  • 최근 모니터링 리스트 — 최근 등록순 목록. 상태 필터 드롭다운으로 좁혀볼 수 있습니다.
💡 등급은 어디서도 직접 입력하지 않습니다. 데이터를 등록하면 시스템이 자동으로 계산합니다.

3-5. 영역 대분류로 필터링하면 — "영역뷰"

상단 필터바의 영역 대분류 드롭다운에서 특정 영역(예: 중대재해, 공정거래 등)을 고르면 화면이 그 영역 전용 레이아웃으로 바뀝니다.

  • 리스크 영역별 현황 도넛이 그 영역의 위반 유형별 현황으로 바뀝니다.
  • 측정판이 선택한 영역 한 칸만 남도록 좁아집니다.
  • 측정판 옆에 최근 모니터링 현황 카드가 추가로 나타납니다.
  • 감사를 선택하면 상단 KPI 4장과 측정판은 숨겨지고, 감사 전용 카드·조치사항 표만 보입니다. 조치사항 표의 행을 누르면 전문(全文) 보기 팝업이 뜹니다(표에서 길게 잘려 보이는 내용을 전체 확인할 수 있습니다).
  • 전체 화면으로 되돌아가려면 필터를 "전체 영역 대분류"로 바꾸거나, 사이드바 상단 로고를 누르면 모든 필터가 초기화되며 첫 화면으로 돌아갑니다.

4데이터 입력하기

사이드바 [데이터 입력] 화면에는 세 가지 입력 방법이 있습니다: 4-1 한 건씩 입력, 4-2 엑셀 일괄 업로드, 4-3 영역별 특이사항.

먼저 알아두기 — 영역별로 '상태' 이름이 다릅니다

영역상태 옵션건수 집계
불법파견/공정거래/영업비밀/IP/재고모니터링 / 위반 / 완료모니터링→모니터링 건수, 위반·완료→위반 건수
부실채권발생 / 해결발생·해결 모두 건수로 집계(둘 다 '일어난 일'이라 전체=위반)
감사적발 / 조치완료위와 동일한 방식(적발=위반계열, 조치완료=완료계열)
중대재해발생 / 조치완료위와 동일
💡 외식BG에서 자동 연동된 영업비밀의 '모니터링' 건수만 화면에 1/10 비율로 표시됩니다. 예를 들어 외식BG에서 모니터링 50건이 넘어오면 화면(KPI·측정판·그래프)에는 5건으로 나타납니다. 이 화면에서 직접 입력한 영업비밀 모니터링 건수는 그대로 표시됩니다. 위반·완료 건수는 어느 쪽이든 그대로 반영됩니다.

4-1. 한 건씩 입력

  1. 계열사 * 를 먼저 고릅니다. → 그 계열사의 브랜드/조직 목록이 자동으로 나타납니다.
  2. 브랜드/조직 * 선택 (유통 계열사는 매장 칸 추가, 선택사항)
  3. 등록일 * — 기본값은 오늘 날짜
  4. 영역 대분류 * 를 고르면 → 관련 영역 중분류와 위반유형 옵션이 자동으로 바뀝니다.
  5. 상태 * — 영역에 따라 버튼 종류가 다릅니다(위 표 참고)
  6. 건수 * — 상태에 맞춰 라벨이 바뀝니다. 숫자를 반드시 입력하세요.
  7. 리스크명 * — 제목을 입력
  8. 감사 영역을 선택한 경우 — 징계유형 · 대상자 · 양형/처분 3가지가 모두 필수입니다. (예: 징계유형=중징계, 양형/처분="정직 3개월")
  9. 부실채권 + 위반유형이 '미입금' 또는 '2개월 초과 미입금'인 경우 — 금액 입력이 필수입니다.
  10. 외부노출 여부 — 해당 건이 언론·SNS 등 외부에 노출됐으면 체크합니다. 컴플라이언스 분류(불법파견/공정거래/영업비밀/IP)에서 이 체크가 등급에 영향을 줍니다(6번 참고).
  11. 조치사항 — 선택. 자유 입력 텍스트로 저장됩니다.
  12. 비고 — 추가 메모 (선택)
  13. [저장] 을 누르면 등록됩니다.
잘못 눌렀다면 [초기화] 로 폼을 비울 수 있습니다.

4-2. 엑셀로 한꺼번에 올리기 (일괄 업로드)

🔒 '보안(암호화)이 해제된' 엑셀 파일만 업로드할 수 있습니다. 회사 문서보안(DRM)이나 비밀번호가 걸린 파일은 "파일 처리 실패" 오류가 납니다.
  1. 양식 다운로드 — 계열사·브랜드·영역 목록이 자동으로 들어간 최신 양식을 받습니다.
  2. 엑셀 작성 — '입력' 시트의 2행부터 작성합니다.
  3. 엑셀 업로드 → 검증 — 등록 가능 N건 / 오류 N건이 먼저 표시됩니다.
  4. 실제 저장 — [유효한 N건 등록] 을 눌러야 저장됩니다.

4-3. 영역별 특이사항 입력

등급 산정과 무관하게, 브랜드별로 발생한 특이 이슈를 메모처럼 남기는 별도 입력란입니다. 날짜·브랜드·주요이슈·이슈상세·조치사항을 적어 저장하면, 대시보드의 조치사항 표 하단 "영역별 특이사항"에 나타납니다.

  • 목록에서 수정 버튼을 누르면 그 자리에서 내용을 고칠 수 있고, 삭제도 가능합니다(삭제는 되돌릴 수 없습니다).
  • 대시보드에 표시된 특이사항 행을 누르면 전문(全文) 보기 팝업이 떠서, 표에서 잘려 보이는 내용을 전체 확인할 수 있습니다.

5등록한 내용 보기·고치기 (모니터링 리스트)

사이드바 [모니터링 리스트] 에서 등록된 리스크를 표로 봅니다.

  • 상단 필터로 계열사 / 영역 대분류 / 영역 중분류 / 상태 별로 골라 볼 수 있습니다.
  • 각 줄에서 수정 또는 삭제를 할 수 있습니다. 삭제는 되돌릴 수 없으니 신중히 사용하세요.

6등급은 어떻게 정해지나요?

등급은 법인(또는 브랜드) × 영역 대분류 단위로 A B C D F 5단계로 자동 계산됩니다. 집계 기간은 측정판의 누적/지정월 설정을 따릅니다.

건수 기준은 월평균입니다. 누적 모드는 (연초~기준일 총 건수)÷(경과 개월수), 지정월 모드는 그 달 건수 그대로입니다. 연말로 갈수록 총 건수만 쌓여 등급이 무조건 나빠지는 것을 막기 위함입니다.

6-1. 기본 등급 (월평균 건수 기준)

등급위반(위반+완료) 월평균 건수
A 우수3건 이하
B 양호4~6건
C 주의7~9건
D 위험10건 이상

6-2. 영역별 F등급(불량) 특별 조건

아래 조건에 하나라도 해당하면 건수와 무관하게 무조건 F 불량입니다.

영역F등급 조건
불법파견 · 공정거래 · 영업비밀 · IP
(컴플라이언스 분류)		외부노출 1건 이상 발생
중대재해'중대재해 발생' 1건 이상 (같은 영역의 '산업재해 발생'보다 심각한 쪽)
부실채권'2개월 초과 미입금' 금액이 1억 초과인 건 발생
부실채권은 금액 기준이 두 방향입니다 — '2개월 초과 미입금' 금액이 1억 이하면 D, 1억 초과면 F입니다. 헷갈리기 쉬우니 주의하세요.
감사·재고는 등급 산정 대상에서 제외됩니다(측정판에 '—'로 표시).

6-3. 종합등급 (측정판의 순위·점수)

법인(또는 브랜드)의 영역별 등급을 점수로 환산한 평균 점수로 계산합니다.

  • 점수 환산: A=10점, B=8점, C=5점, D=3점, F=0점
  • 평균 9~10=A, 7~8=B, 5~6=C, 3~4=D, 3 미만=F
  • 화면에는 평균×10을 100점 만점 점수로 함께 표시합니다.

10자주 묻는 질문 (FAQ)

Q. 가입했는데 로그인이 안 돼요.
→ 관리자 승인 전입니다.

Q. 등급을 직접 바꾸고 싶어요.
→ 등급은 자동 계산이라 직접 입력하지 않습니다. 상태·건수·외부노출 여부 등을 정확히 입력하면 등급이 알맞게 반영됩니다.

Q. 감사 영역인데 저장이 안 돼요.
→ 징계유형·대상자·양형/처분 3가지를 모두 입력해야 저장됩니다.

Q. 부실채권인데 저장이 안 돼요.
→ 위반유형이 '미입금' 또는 '2개월 초과 미입금'이면 금액 입력이 필수입니다.

Q. 영업비밀 모니터링 건수가 화면에서 이상하게 작게 나와요.
→ 외식BG에서 자동 연동된 건이라면 정상입니다. 그 경우에만 모니터링 건수가 1/10 비율로 표시됩니다(위반·완료는 그대로, 이 화면에서 직접 입력한 건은 축소되지 않습니다).

Q. 측정판에서 기준월을 바꿨는데 왜 값이 안 바뀌어요?
→ 새로고침 후에도 안 바뀌면 화면을 다시 열어보세요. 정상적으로는 지정월을 고르면 그 달 데이터만, '이번달'로 되돌리면 연누적으로 다시 계산됩니다.

Q. 엑셀 업로드에서 "헤더가 양식과 다릅니다"가 떠요.
→ 예전 양식을 쓰셨을 가능성이 큽니다. 양식을 새로 다운로드해 다시 작성하세요.

Q. 모바일에서도 되나요?
→ 네. 화면이 작으면 왼쪽 위 메뉴 버튼으로 사이드바를 열고 닫을 수 있습니다.
